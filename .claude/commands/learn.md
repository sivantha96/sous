1. Read `questions.md` in each org (or only $ARGUMENTS).
2. Ask each question with the AskUserQuestion tool: the situation and the choice in under 40 words, two to four options in plain words, the evidence in the message before the question.
3. Write each answer into memory as a rule, a system fact or a habit, one bullet, with the PR it came from. Remove the question from `questions.md`.
4. If the answer settles a thread that is waiting, write the reply in Sivantha's voice and show it with the thread link, for Sivantha to post.
5. Commit each memory folder that changed.
